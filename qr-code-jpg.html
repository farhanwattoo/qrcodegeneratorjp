JPG vs PNG for QR Codes

Factor JPG PNG
File Size Smaller (compression) Larger (lossless)
Transparency ✗ Not supported ✓ Full support
Quality Lossy (compression artifacts) Lossless (perfect copy)
Best For Web, email, quick sharing Print, design, transparency
Scannability ✓ Full at high quality ✓ Perfect

When to Use JPG QR Codes

  • 📧 Email newsletters (faster loading)
  • 🌐 Website images (web optimization)
  • 📱 Social media posts (instant preview)
  • 💾 File storage (save disk space)
  • 🔄 Quick sharing (faster upload/download)
Rule of Thumb: Use JPG for web/email. Use PNG for print/design. Use SVG for scalability.

Quality Settings

JPG Quality Levels

  • Quality 95%: Best for QR codes, minimal compression loss
  • Quality 85%: Good balance between size and quality
  • Quality 75%: Acceptable for web, visible compression
  • Quality 60%: Not recommended (scanning issues possible)

Generation Code

Python

import qrcode
from PIL import Image

qr = qrcode.QRCode()
qr.add_data('https://example.com')
qr.make()

img = qr.make_image(fill_color='black', back_color='white')

# Save as JPG with quality setting
img = img.convert('RGB')  # JPG requires RGB, not RGBA
img.save('qrcode.jpg', quality=95)

JavaScript

// After generating QR code canvas
const canvas = document.getElementById('qrCanvas');

// Convert to JPG (data URL)
const jpgDataUrl = canvas.toDataURL('image/jpeg', 0.95);

// Download
const link = document.createElement('a');
link.href = jpgDataUrl;
link.download = 'qrcode.jpg';
link.click();

Best Practices

  • Use Quality 90%+ to maintain QR readability
  • Test Before Use - scan JPG version on real devices
  • Simple Designs Only - avoid gradients/colors with JPG
  • Web Optimization - Use image optimization tools
  • Consider Format - JPG best for solid colors only
